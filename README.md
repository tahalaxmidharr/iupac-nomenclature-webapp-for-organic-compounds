# **IUPAC NOMENCLATURE APP**

## About the Project

- This is a web app that helps users find the IUPAC names of organic compounds by drawing their chemical structures.

- I built this project because we have been studying organic nomenclature extensively at school. I wondered if I could combine chemistry with computer science to make something useful for learning. That idea led me to build this app.

- The app uses Flask, HTML, JavaScript, the JSME molecular editor, and the PubChem API to convert a drawn chemical structure into its SMILES representation and retrieve its IUPAC name.

- My goal was not just to create a study tool, but also to explore how different subjects can be connected to solve practical problems.
